A NOTE ON REPLAY

Why forecast changes are not shown

A reliable change comparison needs earlier forecasts produced on a comparable basis. This release contains only the current forecast, so there is no previous version to compare.

A day-by-day replay also needs matching, timestamped source inputs for each date. Those records are not available here. The History page shows annual results for the 2018–2024 elections instead; those are historical checks, not a daily replay.

HOW TO READ THE ARCHIVE

Seat estimates, not race-by-race picks

Expected seat totals add each forecast race’s party win chances. They can include fractional seats because they represent averages across outcomes. Current seat ranges are shown only where a saved distribution is available.

Senate totals combine 35 forecast contests with 65 seats not up for election. Governor totals cover the 36 races on the ballot, not all 50 states. Older releases are preserved separately because their source dates and inputs differ; changes between dates should not be read as a clean measure of new data alone.

For retrospective comparisons with polling averages and actual results, see the History page.

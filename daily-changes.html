Seat estimates and race-by-race movement

Expected seat totals add each forecast race’s party win chances, so they can include fractional seats. Race comparisons show changes from the immediately older saved release. Older releases can use different source dates and inputs, so changes are descriptive rather than an estimate of the effect of new polls.

Senate totals combine 35 forecast contests with 65 seats not up for election. Governor totals cover the 36 races on the ballot. For retrospective comparisons with polling averages and actual results, see the History page.
